# tiktok_auth_ios

The iOS implementation of [`tiktok_auth`](https://pub.dev/packages/tiktok_auth),
built on the official TikTok OpenSDK Login Kit 2.5.0. Supports both Swift
Package Manager and CocoaPods.

## Usage

This package is
[endorsed](https://docs.flutter.dev/packages-and-plugins/developing-packages#endorsed-federated-plugin),
so you only need to depend on `tiktok_auth`; this package is added
automatically. See the `tiktok_auth` README for setup instructions.
